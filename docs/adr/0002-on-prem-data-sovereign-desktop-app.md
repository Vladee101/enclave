# ADR-0002: On-prem десктопное приложение с суверенитетом данных

- Статус: Принято
- Дата: 2026-06-29
- Решение принял: Vlad (Softwarean)

## Контекст

Целевые пользователи — организации, чьи документы не могут покидать их контур:
регулируемые отрасли, европейские компании под GDPR, команды с чувствительной
внутренней интеллектуальной собственностью. Для такого покупателя первое и самое
трудное возражение к любому AI-инструменту — «куда уходят наши данные». Смысл
продукта в том, что ответ — *никуда*: документы, эмбеддинги, модель и каждый
запрос остаются на машине пользователя или в его локальной сети.

## Решение

Поставлять продукт как десктопное приложение — оболочка Tauri, интерфейс на
React, ядро на Rust, — которое выполняет весь инференс и хранение локально.
Штатный путь исполнения не делает ни одного сетевого вызова за пределы машины.

## Рассмотренные альтернативы

- **Web SaaS** — полностью уничтожает посылку о суверенитете данных. Посылка и
  есть отличие продукта, так что вариант нежизнеспособен. Отклонено.
- **Десктоп на Electron** — более тяжёлый рантайм, крупнее бинарники и слабее
  профиль безопасности, чем у Tauri с ядром на Rust. Отклонено.
- **Облачный LLM API поверх локальных данных** — данные всё равно покидают
  контур ради инференса, то есть ровно то возражение, на которое мы отвечаем.
  Отклонено.

## Последствия

**Плюсы**
- Максимально сильная история про резидентность данных, а это и есть весь питч.
- Tauri даёт небольшие бинарники и ядро на Rust, подходящее для тяжёлой работы:
  загрузка документов, оркестрация поиска, общение с sidecar-инференсом.

**Издержки**
- Дистрибуция и обновления — на каждую машину, а не один деплой.
- Производительность ограничена железом пользователя. Это приемлемо и
  согласуется с аудиторией локального инференса.
