# ADR-0001: Вести Architecture Decision Records

- Статус: Принято
- Дата: 2026-06-29
- Решение принял: Vlad (Softwarean)

## Контекст

Это портфолио-система, где обоснование архитектуры важно не меньше самого кода.
Решения, принятые молча на этапе проектирования, не видны рецензенту, а через
месяц их мотивация забывается и автором.

## Решение

Использовать Architecture Decision Records. Каждое значимое решение получает
пронумерованный файл в `docs/adr`, написанный в стиле MADR: контекст, решение,
рассмотренные альтернативы, последствия. Принятые записи неизменяемы: решение,
которое поменялось, замещается более поздним ADR, а не переписывается.

## Рассмотренные альтернативы

- **Страница в вики** — расходится с кодом и не хранит историю по каждому
  решению. Отклонено.
- **Только сообщения коммитов** — набор решений не обнаруживается целиком, а
  обоснование тонет в истории. Отклонено.
- **Не записывать вовсе** — теряется рассуждение, то есть самое ценное здесь.
  Отклонено.

## Последствия

**Плюсы**
- След решений проверяем: рецензент (или интервьюер) может пройти ход мысли от
  начала до конца.
- Замещение вместо правки сохраняет историю того, почему всё поменялось.

**Издержки**
- Небольшая постоянная дисциплина: на каждое настоящее решение нужно написать
  запись.
