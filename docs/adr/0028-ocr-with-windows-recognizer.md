# ADR-0028: Сканы читает встроенное распознавание Windows

- Статус: Принято
- Дата: 2026-10-02
- Решение принял: Vlad (Softwarean)

## Контекст

Извлечение текста (ADR-0019) читало только файлы со своим текстом. PDF без
текстового слоя отклонялся с ошибкой «похоже на скан», а картинки нельзя было
загрузить вовсе. В организациях, для которых Enclave делается, сканы — обычное
дело: подписанные договоры, акты, приказы, письма из МФУ.

Распознавание (OCR) должно работать на той же машине, без сети (ADR-0002), и
не утяжелять установщик, который сейчас 22 МБ.

## Решение

**Сканы читает распознавание, встроенное в Windows:** `Windows.Media.Ocr`
поверх рендера PDF `Windows.Data.Pdf`, через WinRT (`ingest/ocr.rs`, крейт
`windows` 0.61 — той же версии, что уже тянет Tauri).

- **Когда.** PDF, у которого нет текстового слоя, — постранично. Картинки
  JPEG, PNG, TIFF (все страницы многостраничного) и BMP распознаются целиком.
  Формат определяется по сигнатуре файла, как и раньше.
- **Как.** Страница PDF рендерится не меньше чем в 300 dpi — разрешение, на
  которое рассчитаны распознаватели. Windows отдаёт размер страницы с учётом
  масштаба экрана, поэтому при масштабе выше 100% выходит чуть больше. Картинка поворачивается по EXIF (фото с
  телефона). Если сторона больше предела распознавателя (10 000 точек),
  изображение уменьшается.
- **Язык.** Языки распознавания — это языковые пакеты Windows. Русский
  предпочитается: его распознаватель читает и латиницу (смешанный
  русско-английский абзац распознан верно), а английский кириллицу не читает.
  Без русского используется язык профиля пользователя.
- **Пометка.** Язык распознавания записывается в `documents.ocr_language`
  (миграция 018), а в списке документов рядом с файлом видно «текст распознан
  (ru)». Так текст, прочитанный машиной, — а на Windows без русского и
  прочитанный неправильно, — заметен.
- **Ошибки.** Пустая страница или слишком плохой скан — ошибка задачи «текст
  не распознан», а не документ «Готов» без текста. Нет ни одного
  распознавателя — ошибка с подсказкой добавить русский язык в Windows.

## Альтернативы

- **Tesseract** (Apache 2.0). Свои языковые модели, не зависящие от Windows,
  и обычно лучшее качество на плохих сканах. Но это 30–40 МБ к первому
  запуску, секунды на страницу, а переносной сборки под Windows нет — её
  пришлось бы собирать самим, как PostgreSQL. Отложено: модуль `ocr.rs`
  отделён так, чтобы Tesseract можно было добавить, если на реальных сканах
  Windows не справится.
- **Модель «со зрением»** (например, Qwen2.5-VL через llama.cpp). Лучше всех
  понимает таблицы и плохие сканы, но это ещё 3–4 ГБ и видеопамять, которой
  на 6 ГБ рядом с чат-моделью нет. Отклонено для текущего железа.

## Проверка

- **Проба на машине разработки.** Страница PDF рендерится за 0,2 с,
  распознаётся за 0,1 с. Русский и английский текст в одном абзаце — без
  ошибок. Единственная ошибка — цифра «3» в ячейке таблицы прочитана как
  «З»; ячейки таблиц идут строками, без структуры.
- **Модульные тесты** на скане 150 dpi — так сканирует обычное офисное МФУ.
  Страница `chromium_ru_en.pdf` отрисована в `tests/fixtures/scan_ru_en.png`
  и вложена картинкой в PDF без текстового слоя (`scan_ru_en.pdf`). Оба пути —
  скан PDF и картинка — дают заголовок, русскую фразу целиком и английскую,
  язык `ru`. Тесты идут только на Windows и пропускаются, если в системе нет
  русского распознавания (`ENCLAVE_REQUIRE_OCR_TEST` превращает пропуск в
  падение).
- **`schema_contract`** выполняет запрос воркера, записывающий язык, на базе
  из одних миграций.

## Последствия

- Сканы и фото документов становятся обычными документами: поиск, цитаты,
  ответы.
- Качество зависит от скана. Распознаётся текст, но не структура: таблица со
  скана — это строки текста, а не таблица для расчётов (ADR-0022).
- На английской Windows без русского языка русские сканы читаются плохо. Это
  видно по пометке «(en-US)» у документа. Лечится добавлением русского языка
  в Windows («Параметры → Время и язык → Язык и регион»).
- PDF, где часть страниц с текстом, а часть — сканы, читается по текстовому
  слою: распознавание включается, только если текста нет совсем.
- Распознавание работает только на Windows. На других системах, куда Enclave
  пока не поставляется, сканы по-прежнему отклоняются.
